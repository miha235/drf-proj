# Django Project in Docker

## Описание
Этот проект запускает Django-приложение с базой данных PostgreSQL, Redis и Celery с использованием Docker и Docker Compose.

## Как запустить проект

### Шаги:
1. Убедитесь, что на вашей системе установлены [Docker](https://www.docker.com/) и [Docker Compose](https://docs.docker.com/compose/).
2. Склонируйте репозиторий:
   ```bash
   git clone <URL вашего репозитория>
   cd <название проекта>
